# GSC-X — Scientific Research Portal

## English

Selected scientific validation datasets and comparative
research results of the GSC-X ecosystem.

The public collection contains scientific documentation
and selected CSV datasets. Proprietary implementation
and production Python source code are not included.

## Česky

Veřejný přehled vybraných vědeckých validací
a srovnávacích výsledků ekosystému GSC-X.

Kolekce obsahuje vědeckou dokumentaci a vybrané
CSV soubory. Proprietární implementace a produkční
zdrojové kódy Python nejsou zveřejňovány.
