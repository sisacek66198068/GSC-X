# GSC-X — Scientific Research & Validation

## English

A structured public collection of selected GSC-X
scientific validation results and benchmark datasets.

The research collection is organized by domain.
Each domain contains documentation and, after approval,
selected CSV validation results.

**No proprietary system source code is included.**

[Validation Index](VALIDATION_INDEX.md)

## Česky

Přehledně organizovaná veřejná kolekce vybraných
vědeckých validací a srovnávacích dat GSC-X.

Každá oblast obsahuje dokumentaci a po schválení
také vybrané validační soubory CSV.

**Proprietární systémové zdrojové kódy nejsou zveřejňovány.**
